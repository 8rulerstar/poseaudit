# Code of conduct

poseaudit follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in issues, discussions, pull requests and anywhere else the project meets
people.

In short: be respectful and patient, assume good faith, criticise work and
not people, and keep in mind that many who ask are new to Python or to
statistics. Harassment, insults and personal attacks are not accepted.

## Reporting

Report anything that breaks this code to the maintainer,
[@8rulerstar](https://github.com/8rulerstar), through the contact on that
GitHub profile. Reports are read in confidence. The maintainer may remove
comments, lock threads or block accounts, as the Covenant's enforcement
guidelines describe.
